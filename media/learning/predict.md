# Predict a value

Predict the answer, then evaluate one expression.

Open the exercise beside this guide. Its comments give the action, the default
key for your platform, and what to look for. Predict first, then compare your
prediction with the captured value.

After evaluating, check: the answer is **14**, because Python multiplies before
adding. Try changing the expression to `(2 + 3) * 4` and predict again.

Nothing runs until you ask Evalens to evaluate. The exercise is an ordinary,
editable Python document; save it only if you want to keep it.

When you have tried the exercise, mark its checkbox yourself. Opening a file
is not counted as completing it. Return with **Evalens: Open Learning Walkthrough**
in the Command Palette at any time.
